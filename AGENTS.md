## Project instructions

- Read this file before making repository changes.
- Keep changes small, reproducible, and documented.
- Do not commit API keys, OAuth tokens, passwords, private certificates, or machine-specific state.
- Keep user/machine credentials outside the repository.
- Preserve existing architecture and conventions unless the task explicitly changes them.
- Run the repository's existing tests, type checks, linters, and build checks when relevant.
- For deployment changes, use environment variables/secrets rather than hard-coded credentials.
- For Codex work, treat repository instructions and trusted project configuration as authoritative for this checkout.
- If behavior or tooling is uncertain, verify against current official documentation rather than guessing.
